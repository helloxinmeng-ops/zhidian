# 支点

> 给我一个支点，我能撬起地球。
> 事再多，只有一个点值得压上全部力气。

一个 macOS 桌面悬浮待办小组件。所有事项共用一条全局序号——排在最前的那件，就是现在该做的那件。

## 功能

- **绝对优先级**：全局唯一连续序号，拖动即重排，跨清单也生效
- **悬浮球**：透明置顶窗口，不占桌面；单击开合面板，点钉子钉住，拖动换位置
- **截止时间与提醒**：到期前弹出卡片，只能点「知道了」或「完成」，不点不消失
- **清单分类**：Tab 切换，计数实时同步；新建默认跟随当前分类
- **完成与清空**：打勾有完成动效、沉入「已完成」区；可一键清空（带确认）
- **数据仅在本机**：localStorage，无账号、无联网、无上传

## 安装

需要 macOS 与 Node.js 18+。在仓库根目录执行：

```bash
npm install   # 首次会下载 Electron（约 100MB）
npm start
```

> 只想先看看？浏览器直接打开 `renderer/index.html` 就是完整交互原型（置顶、提醒等系统能力不可用）。

## 使用

| 操作 | 效果 |
|---|---|
| 单击悬浮球 | 开合面板 |
| 点面板上的钉子 | 钉住 / 取消钉住（不跨重启） |
| 拖动悬浮球 | 移动窗口，位置重启保持 |
| 拖动条目 | 重排全局优先级序号 |
| 输入标题 → Enter | 带出时间选择器 → 再 Enter 创建 |
| 点条目左侧方块 | 完成，动效后沉入「已完成」区 |
| 「已完成 · N」右侧「清空」 | 确认后清空全部已完成项 |

## 说明

- 目前仅在 macOS 验证（透明无边框置顶窗口 + `setVisibleOnAllWorkspaces`）
- 数据存于 Electron userData 的 localStorage，应用内可导出 / 导入 JSON
- 内部技术标识沿用 `floatdo`（包名与 bundle id），仅显示名为「支点」
